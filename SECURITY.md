# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest 0.x release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting instead:

1. Open the [Security tab](https://github.com/mjcumming/health-tree/security).
2. Choose **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and its impact. Include a suggested fix if you have one.

You will get an acknowledgement within 48 hours and a timeline for a fix. Please keep the details private until a fix is released.

## Scope

The library does no I/O and has no runtime dependencies, so most risk sits in the supply chain: the build, the release workflow, and development tools. Reports about those are welcome.
